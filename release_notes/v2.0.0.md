## 用 C#/.NET 重写，界面变回原生

这一版把快投整个换了个底：以前是 Python 后端 + 一个网页界面套在系统浏览器控件里显示，现在是
**C#/.NET 的 WPF 原生桌面程序**。功能一个不少地照搬过来，界面、托盘、投屏窗口右侧那条功能栏
都改成了原生绘制——功能栏以前是用系统底层画图接口硬画的，现在换成矢量图形，有抗锯齿、跟着
屏幕缩放走，不再糊。

## 打包形态变了

- 仍然是**单文件便携版**，双击即用、无需安装，`scrcpy` 与 `adb` 已随包附带
- 现在**连 .NET 运行时也不用装**，目标机器上什么都没有也能跑
- 代价是体积：从约 45MB 涨到约 80MB（换掉「必须装运行时」这件事的必然结果）
- 启动时**不再每次解压**：随包的 `scrcpy`/内置图标首次运行解到
  `%LOCALAPPDATA%\Kuaitou\runtime\`，之后启动直接复用，只在程序真正更新了那批资源时才重解

## 升级说明（重要）

单文件版换过一次技术栈，**老用户的配置只有一种无损的迁移方式**：把下载到的
`Kuaitou-v2.0.0.exe` **改名为 `快投.exe`**，再覆盖掉你原来那个 `快投.exe`。

原因还是老规矩——配置和图标都存在 `快投.exe` 这个文件的 NTFS 数据流里，程序只认文件名。
改了名字就读不到旧数据，等于一切从头设置。文件名、数据流的名字、配置项的名字这一版**一个都没改**，
所以只要文件名对上，旧配置原样可用。

## 功能

- 设备与连接、扫码配对、USB 一键转无线、深度搜索、开机自启动、诊断报告与日志导出：全部保留
- 投屏窗口右侧功能栏的 9 个按钮与 v1.9.0 完全一致，不多不少
- 设置页三大板块的控件一一对应，包括只看不控、关窗熄屏、鼠标捕获这几项

## 界面

- 主题（浅色/深色）换成原生资源令牌，切换即时生效、首屏不闪
- 提示与确认弹窗自绘，跟着主题走，破坏性操作照旧会二次确认
- 键盘可达性补齐：可点元素都能 Tab 到、回车触发，焦点有清晰描边

## 已知差异

- 首次启动会多花一两秒把随包资源解到本机（只这一次，之后启动更快）
- 若杀软拦下写数据流，配置会退回成 exe 同目录的普通文件，诊断报告里会写明用的是哪种
