# 常见问题

**双击没反应 / 界面迟迟不出来**
exe 是自包含的，**不需要装 .NET，也不需要装 WebView2**，正常双击就能起。如果没反应，
先确认下载完整（发布资产名是 `Kuaitou-v版本号.exe`，约 80MB；如果拿到的是被平台清成的
`default.exe`，多半下载方式不对），再检查杀软是否拦截了首次运行。
另外**首次启动会慢一点**（要把随包资源解出来，之后不再重复），第二次起就明显快了。

**从旧版升级后，设置 / 设备记录都没了**
2.0.0 起换成了 C# / .NET 重写，但配置的存放方式没变——还是写在 exe 自身的 NTFS 数据流里，
**按文件名认**。把下载到的 `Kuaitou-v2.0.0.exe` **改名成 `快投.exe`** 再覆盖旧版，
旧配置就能继续用；文件名不一样，程序就当它是另一个程序，读不到原来的数据流。

**状态栏一直停在「等待手机授权」**
手机屏幕要处于解锁状态，并且要有人去点那个「允许 USB 调试」的弹窗。
程序会持续等待并在状态栏提示，超过 120 秒会提示「等待设备就绪超时」，解锁手机重试即可。
（连接过程的失败提示都只走状态栏，不会弹窗打断你。）

**显示「设备离线」**
手机可能熄屏或换了网络。程序会在后台按退避策略自动尝试恢复（6 → 12 → 24 → 60 秒）。
被主动断开的设备不会自动恢复。

**点了「关闭物理屏幕」，手机还是被锁上了**
「关闭物理屏幕」在 **Android 15 及以上**走的是系统命令（`cmd display power-off`）：
只关掉显示电源，手机并没有进入睡眠，锁屏那套逻辑不会启动，所以不会锁。
更早的安卓没有这条命令，只能退回「临时把『熄屏后自动锁定』顶长 + 按电源键」，
这条路成不成取决于 ROM 认不认那条设置（部分 vivo 就不认），被锁上时用主页第一行的「解锁」解开即可。

**扫不出应用 / 投不出画面**
进设置页的「诊断」标签，先点「环境自检」。这个功能就是为「换了一台电脑之后就不对劲」准备的。

**端口扫描为什么那么慢**
「深度搜索」第 3 级要对存活主机扫 30000~50000 端口，边扫边用 `adb connect` 复核，
所以耗时在分钟级。只想快速发现同网段设备用「扫描局域网」就够了；不想等就再点一下
「停止搜索」，已经找到的那些会留下来。

**换电脑 / 拷贝 exe 之后配置没了**
见下方[存储说明](#存储说明)——配置写在 exe 自身的 NTFS 数据流里，复制文件时不会跟着走。

**想反向解决：已经开了两个实例**
程序有单实例保护，重复启动只会把已有窗口唤到前台，不会开出第二份 adb。

## 存储说明

程序生成的配置、日志、图标缓存默认写入 `快投.exe` 自身的 **NTFS 数据流（ADS）**，
使 EXE 保持单文件、目录不留散落文件；在非 NTFS 卷或写入受限时自动回退到
EXE 同目录的普通文件。当前实际用的是哪种方式，可以在「设置 → 诊断」里看到。

> ⚠️ 注意：**ADS 不随文件复制**。把 EXE 拷到 U 盘 / FAT32 分区 / 网络盘，
> 或用压缩包、聊天工具传输时，这些数据会丢失（表现为配置重置）。
> 需要连同配置一起迁移时，请从 EXE 同目录获取回退模式下生成的配置文件。

随包资源（scrcpy、adb、内置图标素材库、默认配置）不落成文件，而是内嵌在 exe 里，
**首次启动**解到 `%LOCALAPPDATA%\Kuaitou\runtime\<一串哈希>\` 下，之后直接从那儿用。
这个目录只跟 exe 内的资源内容有关：换版本后资源变了会自动重解一份，旧的那份可以随时删掉。

日志（`scrcpy_launch.log`、`apps_scan.log`）超过 1MB 会自动截断轮转。
